# CSE134

When I began coding the HTML, the goal was always to be a site that an employer could look at for reference. To achieve this, I need my site to be as readable for the user as possible. I ended up moving the information from Projects and Experience to Custom Cards. All the information is on one page. In addition, Projects and experience are topics that coincide, so there is not much of a point in separating them. As a result, there is no point in having two separate tags, it's easier if it's just one. I also set a link to the form from hw4. When people submit the form there will be a post request that will send that data to the JSON bin. This is my way of checking if people who have checked the website are interested in hiring me in the future.
